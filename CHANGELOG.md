## [1.5.0-alpha.1] - 2026-06-15

### Additions

- Port to 26.1.2 for Fabric
- Port to 26.1.2 for NeoForge

- Long Amethyst Pendulum
  - 2-block version of Amethyst Pendulum
  - Crafted with original pendulum + extra ingots
  - Requires bell behind **top** half to chime
  - Behaves identically otherwise

- Clock Key
  - Item used to wind clock to real-world time
  - Attaches to side of clock and spins to wind
  - Clock time is wound to the player's time zone
  - Different clocks can have different time zones
  - Toggle between in-game time and real-world time

### Changes

- Analog Clock can now be set to a real-world time zone
- Analog Clock time zone setting persists when broken
- Amethyst Pendulum now only chimes if below clock
- Chime only triggers if clock is set to in-game time
